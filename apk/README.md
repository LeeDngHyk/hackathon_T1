# 하루콩 (TECH4GOOD) — 시연용 APK

AI 육아 동화 서비스 "하루콩"의 UI 시연용 데모 앱입니다. 실제 서버·AI 기능은 동작하지 않으며, 디자인 목업 기반의 화면 흐름을 그대로 담았습니다.

## 파일
| 파일 | 대상 | 패키지 | 크기 |
|------|------|--------|------|
| `하루콩_부모용_v1.0.apk` | 부모용 | `com.harukong.parent` | 3.7MB |
| `하루콩키즈_아이용_v1.0.apk` | 아이용 | `com.harukong.kids` | 3.7MB |

> 패키지명이 서로 달라 한 기기에 **두 앱을 동시에 설치**할 수 있습니다.

## 설치 방법 (Android)
1. APK 파일을 안드로이드 기기로 복사합니다.
2. 파일을 눌러 설치 → "출처를 알 수 없는 앱" 허용을 요청하면 허용합니다.
3. 홈 화면에 초록 콩 아이콘의 **하루콩** / **하루콩 키즈**가 생깁니다.

- Android 6.0(API 23) 이상에서 동작합니다.
- 디버그 서명(Android Debug Key)으로 서명되어 있습니다. 마켓 배포용이 아니라 사이드로드 시연용입니다.

## 담긴 화면
**부모용** — 스플래시 → 아이 정보 입력 → 홈(최근 동화·육아일기) → 육아일기 작성(2단계) → AI 동화 생성 → 미리보기 → 전송 완료 → 동화 다시보기(목록·상세·아이 답변) → 리포트(동화별/내면 자아 성장 누적)

**아이용** — 스플래시 → 홈(오늘의 동화) → 동화 시청 → 음성 말해보기(마이크) → 감정 퀴즈 → 행동 퀴즈 → 반응(피드백) → 보상 → 성장 정원
